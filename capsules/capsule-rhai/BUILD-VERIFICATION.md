compiled or packaged input.

## Source fingerprint

Run the checked-in fingerprint command from the capsule directory (the
repository root is the directory containing `capsules/`):

```text
cd capsules/capsule-rhai
./scripts/source-fingerprint.sh
```

The script resolves the repository root from its own path and hashes exactly
the following files.  For each file it records `shasum -a 256 -b` using the
repository-relative path, sorts the complete records with `LC_ALL=C sort`, and
hashes the newline-terminated listing with `shasum -a 256 -b`.  It emits only
the resulting SHA-256 and fails if an input is missing.  The script is itself
an input so edits cannot silently bypass the record.  `BUILD-VERIFICATION.md`
is intentionally excluded because it records this digest rather than being a
compiled or packaged input.

## Build lineage

The official build must also run from the capsule directory so rustup selects
`capsules/capsule-rhai/rust-toolchain.toml` (Rust 1.94.0).  The repository root
is pinned to Rust 1.95.0 for other crates; invoking this capsule from the root
can therefore change the generated bytes and does not reproduce this artifact.
Use this exact working-directory and command shape:

```text
cd capsules/capsule-rhai
CARGO_TARGET_DIR=target aos capsule build . --output <output-dir>
```

The equivalent raw-component build is `cargo build --release` from that same
directory.  Do not align the capsule pin to 1.95.0 without rebuilding and
re-recording every artifact hash.

After extraction, run the import allowlist and component validation checks:

```text

```

The component bytes are reproducible across clean release builds because
production `ahash` uses runtime host entropy rather than Rhai's
compile-time-random seed.  The outer `.capsule` tar.gz is not byte-for-byte
reproducible with the current AOS packer: tar entry mtimes are inherited from
the build/staging filesystem.  Release verification therefore pins and checks
both this exact archive SHA-256 and its embedded WASM SHA-256; it does not
claim deterministic archive bytes until the packer normalizes metadata.
